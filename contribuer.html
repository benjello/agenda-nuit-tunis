Contribuer : les sources qui manquent

Beaucoup de lieux n'annoncent leurs dates que sur Facebook ou Instagram, et on ne connaît pas toujours leur page. Vous pouvez nous aider en cinq minutes, sans rien savoir de technique.

  1. Choisissez un lieu dans la liste ci-dessous.
  2. Cherchez sa page Facebook ou Instagram (ou son site) sur Google ou dans l'appli.
  3. Cliquez sur « J'ai trouvé » et collez l'adresse. C'est tout : on s'occupe du reste.

Une autre source ?

Un lieu, un collectif ou un artiste qui annonce régulièrement ses dates et qui n'est pas encore sur l'agenda : proposez-le aussi.

Proposer une source

Le formulaire s'ouvre sur GitHub : il faut un compte gratuit (2 minutes). C'est aussi notre protection contre les robots.

Pour les développeurs : ajouter la source vous-même

Vous êtes à l'aise avec GitHub ? Ajoutez la source directement dans le registre : ouvrez le fichier, cliquez sur le crayon ✎, copiez une entrée voisine du même type (page Facebook, compte Instagram…), puis « Propose changes ». GitHub prépare la pull request pour vous. Elle est vérifiée automatiquement puis relue avant d'être ajoutée.
